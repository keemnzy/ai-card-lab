# Meetcha 개인정보처리방침 (초안)

> **초안 안내** — 이 문서는 2026-11-18 기준 `meetcha/server` 코드가 실제로 처리하는 정보를 바탕으로 쓴 초안입니다. 공개 전에 변호사나 개인정보 전문가의 검토를 받아야 합니다. `[ ]` 안은 정해지면 채울 부분입니다.

**시행일: [2027-00-00]**

[운영사명](이하 "회사")는 「개인정보 보호법」에 따라 Meetcha 서비스(이하 "서비스") 이용자의 개인정보를 보호하고, 관련 고충을 신속하게 처리하기 위해 다음과 같이 개인정보처리방침을 둡니다.

---

## 제1조 처리하는 개인정보 항목과 목적

회사는 서비스 제공에 꼭 필요한 정보만 처리합니다. **이름 외 프로필 항목은 모두 선택**이며, 전화번호·주민등록번호·주소·결제 정보는 수집하지 않습니다.

| 구분 | 항목 | 목적 | 필수 여부 |
|---|---|---|---|
| 회원 가입·로그인 | 이메일 주소 | 본인 확인, 로그인 링크 발송, 서비스 관련 안내 | 필수 |
| 디지털 명함 | 이름(또는 닉네임) | 명함 표시 | 필수 |
| | 직함, 소속, 한 줄 소개, 외부 링크(LinkedIn 등), 퀴즈 문제와 정답, 이벤트 힌트 | 명함 표시, 퀴즈 기능 제공 | 선택 |
| | 프로필 사진 | 명함 표시 (업로드한 사진은 512×512로 줄이고 촬영 위치 등 사진 속 부가 정보를 모두 지운 뒤 저장) | 선택 |
| 키링 | 키링 식별값(NFC 칩 고유번호 또는 링크 코드), 등록 일시, 분실 신고 여부 | 키링과 회원 연결, 위조·도용 방지 | 키링 등록 시 필수 |
| 만남 기록 | 누가 누구의 키링을 언제 태그했는지, 태그한 행사, 정품 칩 확인 여부 | 도감 기능, 공개 범위 판단 | 서비스 이용 시 자동 생성 |
| 퀴즈 | 퀴즈 풀이 기록, 점수 | 점수·최고 기록 표시 | 서비스 이용 시 자동 생성 |
| 메모·메시지 | 본인이 작성한 메모, 주고받은 메시지, 차단 목록 | 메모·메시지 기능, 원치 않는 연락 차단 | 이용 시 |
| 행사 | 체크인 일시, 리더보드 공개 동의 여부 | 이벤트 모드(발견 보드, 리더보드) 제공 | 행사 참여 시 |
| 행사 참가자 명단 | 행사 주최사가 제공한 이메일, 이름, 직함, 소속 | 행사 전 안내 메일 발송, 가입 시 프로필 미리 채우기 | 주최사가 명단을 제공한 경우 |
| 동의 기록 | 동의한 약관·처리방침 버전, 동의 일시 | 만 14세 이상 확인과 동의 사실 증빙 | 가입 시 자동 |
| 신고 | 신고한 사람, 신고 대상, 사유, 상세 내용, 처리 결과 | 괴롭힘·사칭 등 부정 이용 대응, 이용 제한 | 신고 시 |
| 이용 제한 | 정지 기간, 정지 사유 | 약관 위반 회원의 이용 제한 | 제한 시 |
| 자동 수집 | 로그인 상태 유지용 쿠키, 접속 IP 주소, 접속 일시, 로그인 기록 | 로그인 유지, 과도한 요청 차단, 부정 이용 방지, 보안 사고 대응 | 자동 |

**행사 주최사로부터 받는 정보**: 행사 주최사가 참가 신청자 명단(이메일, 이름, 직함, 소속)을 회사에 제공할 수 있습니다. 회사는 이 정보를 행사 전 안내 메일 발송과 가입 시 프로필 미리 채우기에만 쓰며, 가입하지 않은 사람의 명단은 행사 종료 30일 후 삭제합니다. 주최사는 참가자에게 이 제공 사실을 알릴 책임이 있습니다.

**다른 사람에 대한 정보**: 이용자가 작성하는 메모에는 다른 사람에 대한 내용이 들어갈 수 있습니다. 메모는 작성한 본인만 볼 수 있으며, 회사는 메모를 다른 목적으로 이용하지 않습니다.

## 제2조 개인정보의 처리 및 보유 기간

회사는 회원 탈퇴 시까지 개인정보를 보유하며, 아래 정보는 더 짧게 보유합니다.

| 항목 | 보유 기간 |
|---|---|
| 로그인 링크 | 발급 후 15분간 유효, 만료 후 1일 이내 삭제 |
| 로그인 상태(세션) | 최대 30일 또는 로그아웃 시까지 |
| 로그인 전 태그 기록 | 30분 (그 안에 로그인하지 않으면 삭제) |
| 과도한 요청 차단용 IP 주소 | 서버 메모리에만 최대 1시간, 저장하지 않음 |
| 이벤트 힌트 공개 | 행사 시간 중에만 다른 참가자에게 보임 |
| 가입하지 않은 사람의 행사 참가자 명단 | 행사 종료 30일 후 자동 삭제 |
| 로그인 기록(접속 IP, 일시) | 3개월 후 자동 삭제 (탈퇴해도 이 기간 동안 보관) |
| 신고 기록 | 접수 후 1년 후 자동 삭제 (탈퇴해도 이 기간 동안 보관, 부정 이용 재발 방지 목적) |

법령에 따라 보존해야 하는 경우 해당 기간 동안 보관합니다.
- 「통신비밀보호법」에 따른 접속 기록(로그인 기록, 접속 IP 등): 3개월

## 제3조 개인정보의 제3자 제공

회사는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 다음은 이용자 본인의 선택에 따라 다른 이용자에게 보입니다.

1. **명함 공개 범위**: 이용자가 정한 범위에 따라 명함이 다른 이용자에게 보입니다.
   - 전체 공개: 누구나 봄
   - 만난 사람만(기본값): 키링을 서로 태그한 사람만 봄. 그 외에는 이름만 보임
   - 비공개: 본인 외에는 이름만 보임
2. **이벤트 모드**: 행사에 체크인하면 같은 행사 참가자에게 본인이 입력한 힌트가 보이고, 키링을 태그한 사람에게는 명함이 보입니다. 행사 중에 다른 사람의 키링을 태그하면 그 사람에게 내 이름이 알림으로 표시됩니다.
3. **연락처 저장**: 내 명함을 볼 수 있는 사람은 그 내용(이름, 직함, 소속, 한 줄 소개, 외부 링크)을 자기 휴대폰 연락처로 저장할 수 있습니다. 이메일 주소는 포함되지 않습니다.
4. **행사장 대형 화면**: 주최사가 행사장 화면에 리더보드를 띄우면, 리더보드에 동의한 사람의 이름과 만난 사람 수가 그 화면에도 보입니다. 개인에게 가는 알림은 대형 화면에 표시되지 않습니다.
5. **리더보드**: 체크인할 때 동의한 경우에만 이름과 만난 사람 수가 같은 행사 참가자에게 보입니다(리더보드와 실시간 활동 소식). 동의하지 않으면 활동 소식에 "참가자 한 명"으로만 표시됩니다.

**행사 주최사(기업 고객)에게는** 참가자 수, 만남 수, 평균 퀴즈 점수 등 **개인을 알아볼 수 없는 통계만** 제공합니다. 개인별 정보를 주최사에 제공해야 할 경우 그때마다 제공받는 자, 목적, 항목, 보유 기간을 알리고 별도로 동의를 받습니다.

법령에 특별한 규정이 있거나 수사기관이 법령에 정해진 절차에 따라 요구하는 경우는 예외로 합니다.

| 수탁자 | 위탁 업무 |

## 제6조 개인정보의 파기

1. **파기 사유**: 회원 탈퇴, 보유 기간 만료, 처리 목적 달성
2. **파기 방법**: 전자 파일은 복구할 수 없는 방법으로 삭제합니다.
3. **회원 탈퇴 시 처리** (제2조의 로그인 기록과 신고 기록은 보관 기간이 끝난 뒤 삭제)
   - 즉시 삭제: 이메일, 직함·소속·한 줄 소개·힌트, 외부 링크, 퀴즈, 내 도감, 작성한 메모와 나에 대한 메모, 주고받은 메시지, 차단 목록, 퀴즈 풀이 기록, 행사 참여 기록, 로그인 상태
   - 키링: 회원과의 연결을 끊고 사용 중지합니다.
   - 다른 이용자의 도감: 그 이용자가 나를 만났다는 기록은 남지만 **"탈퇴한 사용자"로만 표시**되고, 이름과 연락처 등 나를 알아볼 수 있는 정보는 남지 않습니다.
4. 백업 데이터는 [30일] 안에 순차적으로 삭제됩니다.

## 제7조 이용자의 권리와 행사 방법

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

1. **열람**: '내 명함'과 '내 도감'에서 본인 정보를 확인할 수 있습니다. 전체 정보의 열람을 원하면 아래 개인정보 보호책임자에게 요청하세요.
2. **정정**: '내 명함'에서 직접 고칠 수 있습니다.
3. **삭제**: 항목별로 직접 지우거나 회원 탈퇴로 전부 삭제할 수 있습니다.
4. **처리 정지**: 공개 범위를 '비공개'로 바꾸거나, 리더보드 공개 동의를 거두거나, 특정 이용자를 차단할 수 있습니다.

요청은 [이메일 주소]로 하실 수 있으며, 회사는 요청을 받은 날부터 10일 이내에 처리 결과를 알려 드립니다. 법정대리인이나 위임을 받은 사람을 통해서도 요청할 수 있습니다.

## 제8조 만 14세 미만 아동

서비스는 만 14세 이상만 가입할 수 있으며, 만 14세 미만 아동의 개인정보는 수집하지 않습니다.

## 제9조 개인정보의 안전성 확보 조치

1. **관리적 조치**: 개인정보를 다루는 운영진을 최소한으로 지정하고 정기적으로 교육합니다.
2. **기술적 조치**
   - 모든 통신은 암호화(HTTPS)합니다.
   - 로그인 링크, 로그인 상태 값, 키링 링크 코드와 등록 코드는 **원래 값을 저장하지 않고 복원할 수 없는 해시 값만 저장**합니다.
   - 위조 방지 NFC 칩은 태그마다 암호 서명을 확인해 복사된 링크를 걸러 냅니다.
   - 퀴즈 정답은 서버에만 두고 다른 이용자에게 보내지 않습니다.
   - 과도한 요청을 자동으로 차단하고, 다른 사이트에서 위조한 요청을 거부합니다.
   - 운영진 기능은 지정된 계정만 쓸 수 있습니다.
3. **물리적 조치**: 데이터는 [호스팅 업체]의 보안 시설에 보관합니다.

## 제10조 쿠키의 설치·운영 및 거부

1. 회사는 로그인 상태를 유지하기 위해 쿠키(`mc_session`)를, 로그인 전에 태그한 키링을 로그인 후 도감에 저장하기 위해 쿠키(`mc_pending`, 30분)를 사용합니다.
2. 광고나 행태 분석 목적의 쿠키는 사용하지 않습니다.
3. 브라우저 설정에서 쿠키를 거부할 수 있지만, 이 경우 로그인이 필요한 기능을 이용할 수 없습니다.
