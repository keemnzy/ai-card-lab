## 2. 가입 화면에 넣을 동의 문구 (제안)

화면 디자인할 때 아래 세 가지를 각각 체크박스로 받는다. 한꺼번에 "전체 동의" 버튼을 둬도 되지만 항목별로 고를 수 있어야 한다.

```
[필수] 만 14세 이상입니다.
[필수] 이용약관에 동의합니다. (보기)
[필수] 개인정보 수집·이용에 동의합니다. (보기)
        수집 항목: 이메일, 이름
        목적: 회원 식별, 로그인, 디지털 명함 표시
        보유 기간: 탈퇴 시까지 (법령에 따른 보존 기간 제외)
        동의를 거부할 수 있으나, 거부하면 가입할 수 없습니다.
```

행사 체크인 화면에는 별도로:

```
[선택] 리더보드에 내 이름과 만난 사람 수를 보여 줍니다.
```

## 4. 영문판

영문판은 한국어판 번역이 아니라 해외 법에 맞춰 따로 썼다. 내용(수집 항목, 보유 기간, 공개 범위)은 한국어판과 같고, 아래가 추가됐다.

- **GDPR (EU·영국)**: 처리 목적별 법적 근거, 열람·정정·삭제·처리 제한·이동·반대 권리, 감독기관 신고권, 국외 이전 근거. 한국은 EU의 적정성 결정을 받은 국가라서 EU에서 한국으로의 이전은 별도 계약이 필요 없다.
- **미국 주법 (캘리포니아 CCPA/CPRA, 버지니아·콜로라도 등)**: 수집 항목 범주, 판매·공유 안 함 고지, 열람·정정·삭제 권리, 차별 금지, 대리인 요청, 거부 시 이의 제기.
  - CCPA는 연 매출 약 2,600만 달러 이상, 또는 캘리포니아 소비자 10만 명 이상 등 기준을 넘는 회사에만 의무다. 초기에는 대상이 아닐 가능성이 높지만, 실리콘밸리 사용자의 신뢰를 위해 미리 넣었다.
- **이용 연령**: 만 14세 이상. EU 일부 국가는 16세라서 "거주 국가 기준이 더 높으면 그 기준"으로 적었다.
