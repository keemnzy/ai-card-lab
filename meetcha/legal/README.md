## 2. 가입 화면에 넣을 동의 문구 (제안)

화면 디자인할 때 아래 세 가지를 각각 체크박스로 받는다. 한꺼번에 "전체 동의" 버튼을 둬도 되지만 항목별로 고를 수 있어야 한다.

```
[필수] 만 14세 이상입니다.
[필수] 이용약관에 동의합니다. (보기)
[필수] 개인정보 수집·이용에 동의합니다. (보기)
        수집 항목: 이메일, 이름
        목적: 회원 식별, 로그인, 디지털 명함 표시
        보유 기간: 탈퇴 시까지 (법령에 따른 보존 기간 제외)
        동의를 거부할 수 있으나, 거부하면 가입할 수 없습니다.
```

행사 체크인 화면에는 별도로:

```
[선택] 리더보드에 내 이름과 만난 사람 수를 보여 줍니다.
```

## 4. 영미권 사용자

주 사용자가 실리콘밸리 등 영미권이면 영문판이 필요하고, 한국 법만으로는 부족하다.

- **미국 캘리포니아(CCPA/CPRA)**: 개인정보를 판매하거나 공유하지 않는다는 고지, 열람·삭제 요청 방법 안내. 연 매출이나 처리 규모 기준에 미달하면 의무 대상이 아닐 수 있으니 확인 필요.
- **유럽 사용자가 있으면 GDPR**: 처리의 법적 근거(계약 이행, 동의 등) 명시, EU 대리인 지정 여부 검토.
- 영문판은 이 한국어판을 번역하기보다, 위 항목을 추가해 별도로 쓰는 게 좋다.
